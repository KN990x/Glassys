# Manual check after a clean install (Linux or macOS, Node 22.13+).

1. `curl -fsSL https://raw.githubusercontent.com/KN990x/Glassys/main/scripts/install.sh | bash` (already in the repo: `bash scripts/install.sh` or `pnpm install && pnpm run service:install`; foreground: `pnpm run build && GLASSYS_DATA_DIR=./data node gateway/dist/index.js`)
2. Open the PWA on localhost. Complete operator password + adapter + absolute cwd. For Cursor, sign in with the **Cursor SDK** (URL in the PWA if no host browser) or set an API key. Being logged into cursor-cli / the IDE is not enough. The wizard will not finish Cursor without one of those.
3. First message: thinking, tools, diffs, and text stream from the first token. Cursor default is Grok 4.6 Extra high when that catalog is live; otherwise the composer bar shows a short fallback warning beside the model chip, with the SDK error only in its tooltip.
4. Second message in the same thread (resume / same agentId). Switch to an archived thread with `resumeOnStart: false` in Settings; the next message must **resume** the vendor session, not `create` a new agent. The Glassys transcript of that thread stays.
5. Cancel an in-flight run, from the red stop button (send turns into it while a run is live) or with `Esc`. Running tool rows stop spinning. A queued follow-up message should still run afterward.
6. Leave a run going past 100s; the WebSocket must stay up (keepalive).
7. Change model in the composer; next message still works (same thread). Change cwd or adapter; UI warns that the live thread is archived and a new one starts. The old transcript stays in the thread list.
8. Restart the gateway process; reopen the PWA; the thread snapshot and agent resume still work when `resumeOnStart` is true. With `resumeOnStart: false`, the gateway does **not** resume on process start; the next send after a thread switch still resumes.
9. `pnpm test` (protocol, adapters, gateway, web) is green.
10. Bind `0.0.0.0` with an empty origin allowlist: a PWA Origin whose host matches the request `Host` header must connect. Changing cwd or adapter archives the chat; the previous transcript remains in the thread list. WebSocket clients with **no Origin** (non-browser) are allowed.
11. Phone: wizard/Settings QR + copy uses `publicUrl` from `GET /api/reachability` when set, otherwise the page origin; if bind is loopback, the warning is visible. Workspace picker lists recents, the typed root even when it is not a git repo, git repos under that root, **and** immediate non-git subdirectories.
12. The permission chip leads with a shield coloured by exposure (review, sandboxed auto-run, auto-run without sandbox), opens switches for sandbox / auto-run / permission mode, and **confirms** before saving (that archives the live thread); the confirm is the in-app dialog, never `window.confirm`. The thread list updates from `threads.snapshot` without a reload, in the desktop rail and in the phone sheet. A denied tool shows a red Denied badge on its row, including ACP `cancelled` when auto-run off; a clean step is only a grey check. Attach or **paste** an image with sandbox on; the agent must be able to read `$cwd/.glassys-uploads/` (bytes also stay under `data/uploads/`). File picker is gallery + camera, not capture-only.
13. Queue a follow-up while a run is in flight; the rail status reads Working · queued, not only Queued, and the queue band sits on top of the composer. Remove the follow-up from the queue; the retracted user bubble stays in the transcript. `run.cancel` does not drop later queued messages. Changing cwd/adapter/options while something is queued retracts those jobs. The rail names each workspace once with its threads nested under it, badges a thread's adapter only when it is not the current one, and can rename and delete a thread from the row. On a phone, Enter does not send (use the send button); Back closes Settings / the thread sheet instead of leaving the PWA.
14. Bind/port change (yaml) surfaces a restart banner with **Restart now** (`POST /api/admin/restart`).
15. Command palette (`⌘K` / `Ctrl+K`): groups (commands / workspaces / ops templates) are visible. **Upgrade** opens Settings on the Updates tab and does not POST until you confirm. Restart asks for confirm. Slash `/` only lists templates.
16. An empty transcript offers `/status` `/disk` `/failed-units` as cards with a glyph under the host line; they insert the same text as slash, without sending. The composer keeps its height when you start typing.
17. Loopback banner is dismissible for the tab (does not cover the transcript after dismiss). A reconnect on a huge transcript may show “older messages omitted”; **Export** still has the full file.
18. Settings: the notify switch subscribes or unsubscribes immediately (the flag is saved with that click). Creating a schedule sends the live `threadId`. Times show the gateway timezone; `lastRun` / `lastError` appear after a fire.
19. Upgrade with a dirty git tree is refused (PWA copy + HTTP 409) before spawn. `GET /api/admin/update` still reports status when the service is installed even if the unit is failed.
20. A run that fails on unreadable attachments must not later emit `run.stalled`. After a cancel timeout, the next send does not collide with a leftover adapter `wait()`.
21. File picker / paste / drop refuses a 5th attachment before upload; dragging a file over the composer shows a dashed drop target. The rail can filter by title; export, rename and delete are in the topbar's … menu, and ⌘F opens search in the topbar with a match count.
22. Workspace picker: browsing `/Users` or `/home` returns only the operator home, not other users. Health after `service:install` probes loopback and then `GLASSYS_BIND` if that is a LAN IP.
23. Settings opens on tabs: appearance, agent, session, templates, schedules, updates, phone, usage. The dialog keeps one height across tabs. There is no footer until something is unsaved; then a bar offers Discard and Save, theme and language preview live and revert on Discard, and closing with unsaved changes asks first.
24. Both themes: every screen in dark and light, including the settings dialog, the command palette, tool rows and groups, the Activity panel, and the confirm dialog.
25. Activity (`⌘I`, or the topbar button): Commands lists each shell call with its outcome, Files lists each path once with rewrites first and their +/−; clicking a row scrolls the transcript to that call and flashes it. At 1280px and up it is a column, below that a sheet. It reopens in the state you left it.
26. `⌘B` collapses the rail to a 56px strip and it stays collapsed after a reload. A run of four or more clean tool calls folds into one "N steps" band; a running or failed call keeps its band open.

On a phone viewport, also: the bottom tab bar reaches Chat / Threads / Activity / Settings and clears the home indicator, the sheet filter is usable, loopback dismiss works, and the shortcut line under the composer is **hidden** (there is no keyboard). The composer bar fits without truncating: the model chip shows the model name only and the permission chip only its shield, and the ⚡ button opens saved prompts. Settings is a list you drill into, with a back control. Below 1024px the rail is replaced by that tab bar; above it, the rail is present and the sheet is not mounted.

Cursor is the golden path for steps 4, 7, and 8. Other adapters must not advertise `source: "live"` unless they listed models from the runtime, and must not advertise `resume` / `autoRun` unless the runtime honors them. Gemini, Codex, and ACP use a static catalog (`liveCatalog: false`); that is not a failure. Gemini’s SDK (`@google/gemini-cli-sdk`) is not published on npm yet — `GET /api/adapters` marks it `available.ok: false`, the wizard/Settings radio is disabled, and `config.set` rejects selecting it or completing onboarding with it. Link the SDK on the host to make Gemini selectable.

Keepalive is clamped to 15–30 seconds (default 25) and is read per WebSocket connection. After a reconnect during a run, the PWA must not stay stuck on Working: the handshake ends with a current `session` after `transcript.snapshot`. The runtime does not call `adapter.resume` when `capabilities.resume` is false unless the adapter’s `shouldResume` says the child can load (ACP persists that after `initialize`). ACP `autoRun: false` denies `fs/write_text_file` and `terminal/create`; cancelled calls paint as Denied. Settings cannot save ACP without `agent.options.command`. The PWA creates/switches/deletes threads over HTTP; WS `thread.new` / `thread.switch` remain for other clients.
